Blitztext4Win

Sprich. Automatisch tippen lassen. In jeder App. Auf jedem Windows-PC.

01 Mehrwert

Blitztext4Win ist ein System-Tray-Tool für Windows, das gesprochene Sprache per Hotkey direkt an die Cursorposition schreibt — ohne Fensterwechsel, ohne manuelles Einfügen.

⚡

Kein Kontextwechsel

Hotkey drücken, sprechen, loslassen — der Text erscheint sofort am Cursor. Kein Fenster öffnen, nicht zwischen Apps wechseln.

🎯

Drei KI-Modi

Plus formuliert gesprochene Sprache in sauberen Text um. Rage macht aus frustrierten Ansagen höfliche Nachrichten. Emoji fügt automatisch passende Emojis ein.

🔒

100% offline mit faster-whisper

Dank faster-whisper läuft die Transkription komplett lokal auf der CPU — keine Internetverbindung, keine API-Kosten, keine Daten in der Cloud.

🎛️

Voll konfigurierbar

Sechs Tabs im Settings-Fenster: Hotkeys frei belegbar, Prompts editierbar, Snippets für Keyword-Ersetzung, Eigennamen für bessere Erkennung.

📋

Portabel & autark

Eine EXE, kein Installer, keine Python-Installation nötig. Clipboard-Swap + Ctrl‑V funktioniert in jeder App, die Einfügen unterstützt.

🛡️

API-Key-Sicherheit

Keys leben ausschließlich in .env (gitignored). config.json enthält nie einen Key — kein versehentlicher Push mehr möglich.

02 Die vier Modi

Normal Rechte Strg Whisper-Transkript 1:1, keine Nachbearbeitung Whisper
Plus Rechte Alt GPT formuliert gesprochene Sprache in sauberen Text um Whisper + GPT / LLM
Rage Rechte Strg + Rechte Alt Wütender Text wird in höfliche, professionelle Nachricht umgeschrieben Whisper + GPT / LLM

Alle Hotkeys sind im Einstellungsfenster frei konfigurierbar. Unterstützte Tasten: ctrl_r/l, alt_r/l, shift_r/l, cmd, F13-F15, scroll_lock, pause.

03 Transkription — Whisper, faster-whisper & Cloud

⚡
Warum faster-whisper und nicht das reine Whisper?
faster-whisper ist keine eigene KI, sondern eine effizientere Laufzeitumgebung (CTranslate2) für Whisper-Modelle. Es ist bis zu ~4× schneller, braucht weniger RAM und läuft produktiv auf der CPU (int8-Quantisierung) — kein GPU-Zwang. Deshalb ist es der Default für lokale Transkription in Blitztext4Win.

Whisper vs. faster-whisper — Detailvergleich

Whisperfaster-whisper
Was ist es? Das Original-Sprachmodell von OpenAI für Speech-to-Text (und teilweise Übersetzung ins Englische). Effizientere Ausführungsumgebung für Whisper-Modelle, umgesetzt mit CTranslate2. Keine neue KI — dasselbe Modell, schneller ausgeführt.
Tempo Standard-Whisper (Referenzgeschwindigkeit) Bis zu ~4× schneller in den meisten Setups
Ressourcen Höherer RAM-Verbrauch, GPU dringend empfohlen Weniger RAM, läuft produktiv auf CPU (int8-Quantisierung)
Wann nehmen? Wenn man das originale OpenAI-Modell meint oder Beispiele exakt darauf aufbauen. Default für lokale Transkription — bessere Geschwindigkeit, effizientere Hardware-Nutzung, kein Netzwerk nötig.

Blitztext4Win erkennt den Provider automatisch am API-Key-Präfix. Kein API-Key nötig → lokaler Modus.

07 Snippets, Eigennamen & Erweiterungen

📝

Snippet-System

Gesprochene Keywords werden nach der Transkription automatisch durch konfigurierten Text ersetzt. „freundliche grüße" → „Mit freundlichen Grüßen". Case-insensitive, per re.sub.

🏷️

Eigennamen

Eine Liste von Namen/Marken wird als Whisper-Prompt übergeben und verbessert die Erkennungsgenauigkeit für schwer erkennbare Eigennamen.

🔮

Geplante Erweiterungen

Fünfter Modus (Zusammenfassen, Übersetzen, Code-Kommentar), mehrere Profile mit unterschiedlichen API-Keys, Hotkey-Konflikt-Erkennung, noch bessere faster-whisper-Modelle.
